# Hemorragias del 3.er trimestre del embarazo

Presentación interactiva (HTML + CSS + JS, sin dependencias) del seminario de cuidados de enfermería.

- Flechas del teclado o botones para navegar, índice, pantalla completa, gestos táctiles.
- Acordeones, tabla comparativa y quiz final.

Abrir `index.html` en el navegador.
